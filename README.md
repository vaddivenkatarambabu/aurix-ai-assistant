# AURIX AI Assistant

AURIX is a personal AI assistant project being rebuilt from scratch.

## Planned features

- Voice input and assistant responses
- AI-powered conversations
- Cross-platform browser opening
- Desktop application actions
- Market information integrations
- Automated tests and structured logging

These features are planned, not all implemented.

## Requirements

- Windows 10 or Windows 11
- Python 3.13
- Git
- A microphone for voice functionality
- An API key when cloud AI integration is implemented
